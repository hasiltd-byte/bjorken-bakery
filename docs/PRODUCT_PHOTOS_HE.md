# תמונות המוצרים

כל 10 המוצרים קיבלו תמונות מקור מהתיקייה שסופקה. הוכנו 19 תמונות WebP, ללא חיתוך ובגובה/רוחב מרבי של 1600 פיקסלים. רשימת הקבצים והשייכות למוצרים נמצאת ב־`visual-references/product-photos-v3.json`.

בהתאם לאישור המשתמש, המוצר שהיה ״עוגות שמרים״ נקרא כעת **״עוגת דבש״** ומשתמש בקובץ שמתחיל ב־`798516250`. מזהה המוצר נשאר קבוע כדי לשמור על קשר להזמנות קיימות.

התמונות הועלו דרך API הניהול ל־Cloudinary. ב־MongoDB נשמרים `image` ו־`gallery` כקישורים בלבד. במנהל `/admin/menu` ניתן להחליף תמונה ראשית, להוסיף תמונות לגלריה, להסירן מהגלריה או לבחור אחת מהן כתמונה הראשית. השינויים מתפרסמים לאחר ״שמירת המוצר״.

בקטלוג התמונה ממלאת את המסגרת וממורכזת, ללא רקע מטושטש. בתצוגה המוגדלת מוצגת התמונה המקורית במלואה. לחיצה פותחת תמונה מוגדלת, גלריה ובחירת כמות, עם אפשרות להוסיף לסל או להמשיך להזמנה. גם התמונות בסל ובאזורי התוכן לחיצות. מחיר חסר נשאר ״מחיר באישור המאפייה״.

`node scripts/migrate-product-photos.mjs --apply` מבצע את העדכון המפורש דרך השרת המקומי בפורט 3030. ההעלאות נשמרות במטמון מקומי כדי לא להעלות שוב קבצים שכבר הועלו. הסקריפט אינו משנה מחירים, מלאי, זמינות או הגדרות העסק. מספר ה־WhatsApp לבדיקה נשאר 0504453592.

בדיקות: `npm test`, `npm run test:browser`, `npm run build`. בדיקת התמונות האמיתיות: `node scripts/verify-product-photos.mjs` לאחר ההעלאה והרצת השרת המקומי. בדיקות הדפדפן משתמשות במסד נפרד ועוצרות מעבר ל־WhatsApp; הן אינן שולחות הודעות.

העדכון במסד בוצע. תצוגת התמונות וחלון ההזמנה החדשים מצריכים פריסה של גרסת הקוד המעודכנת ל־Vercel.
