# חלופות עיצוב להצגה ללקוח

דף השוואה: `/designs`.

בראש האתר המקורי מופיע כפתור **״לעיצובים הנוספים״** המוביל לדף ההשוואה. שלוש האפשרויות נשארות זמינות להצגה. אחרי בחירת הלקוח ייווצר עותק נפרד של העיצוב שנבחר; לאחר מכן יוחלפו המיתוג והתמונות בשלוש הדוגמאות לשימוש עם לקוחות אחרים. ההפרדה והסבת הדוגמאות ממתינות לבחירה.

## 01 · שמש צפונית

קישור: `/designs/sunlight`.

גווני חמאה וירוק זית, כותרות בסגנון סריף, פתיח מרכזי, תמונת מאפים במסגרת רחבה ומעוגלת וכרטיסי מוצרים עם קשתות. פרק הסיפור מופיע לפני הקטלוג. בהשראת הרפרנס הצהוב עם המסגרת הירוקה והקווים המעוגלים.

## 02 · חומר וחום

קישור: `/designs/hearth`.

גווני שמנת, טרקוטה וחום עמוק, כותרות עבות, פתיח מחולק עם צילום גדול וקטלוג כהה עם כרטיסים אופקיים בהירים. בהשראת הרפרנסים של מאפייה כפרית עם טיפוגרפיה בולטת וצילומי מאפים גדולים.

## התנהגות משותפת

החלופות משתמשות באותו רכיב `Bakery`, באותו API, בקטלוג MongoDB הקיים ובתמונות Cloudinary. מוצרים, מחירים, שעות ומספר WhatsApp נשארים מנוהלים באותו ממשק מנהל. לכל חלופה כתובת נפרדת וכפתורי מעבר לעיצובים האחרים. העיצוב המקורי נשאר ב־`/`.

כותרת הפתיח השיווקית קבועה לכל חלופת תצוגה כדי להמחיש את הכיוון; התיאור, הכתובת ונתוני העסק נלקחים מהגדרות המנהל. צילום הפתיח והסיפור בחלופות נלקח ממוצרי הקטלוג.

תמונות המוצרים ממלאות את כל המסגרת ב־`object-fit: cover` וממורכזות. אין רקע מטושטש או הגדלת hover. לחיצה פותחת את התמונה המקורית בתצוגה מלאה, גלריה ואפשרות להזמין. פתיחת WhatsApp נשארת בלשונית נפרדת והסל מתאפס במעבר אליו.

תמונות התצוגה בדף ההשוואה הן צילומי מסך אמיתיים של החלופות, ב־`public/design-previews`. לעדכונן: הריצו שרת מקומי בפורט 3030, ואז `node scripts/capture-design-options.mjs`.

בדיקות המובייל כוללות 320/360/390/430/768 פיקסלים, ומחשב 1440 פיקסלים. `npm run test:browser` בודק גם הזמנה מכל חלופה עם מסד מבודד ופתיחת WhatsApp מיורטת. אין שליחת הודעות אמיתיות בבדיקות.

החלופות נוספו לקוד המקומי. לקבלת קישורים נגישים ללקוח באינטרנט יש לפרוס את הגרסה המעודכנת ל־Vercel.
