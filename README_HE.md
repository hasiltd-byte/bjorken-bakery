# Björken | ביורקן

זהו פרויקט Next.js App Router יחיד, בגרסה היציבה העדכנית שנבדקה: 16.4.2, עם MongoDB/Mongoose. ה־API פועל ב־Route Handlers של Next.js וקוד השרת תחת `lib/server`. אין תיקיית backend או שרת נפרד. הוראות מבנה והפעלה רגילה: [README](README.md).

האתר נבנה על בסיס המקור המלא המקומי של קוטה, בלי לשנות אותו ובלי להעתיק סודות או נתוני לקוחות.

- אתר מקומי: http://localhost:3030
- מנהל: http://localhost:3030/admin
- מוצרים ותמונות: http://localhost:3030/admin/menu
- פרטי כניסה מקומיים: `.local/ADMIN_ACCESS.txt` — נוצרים אקראית בהפעלה הראשונה.
- הפעלה עם Atlas: `START-BJORKEN.cmd`, או `npm.cmd run build` ואז `npm.cmd start`. לפיתוח: `npm.cmd run dev`.

זהו Preview המחובר כעת ל־MongoDB Atlas במסד `bjorken_dev`. שינוי במנהל נשמר ב־Atlas ומופיע באתר אחרי רענון. אין צורך לערוך קוד כדי לעדכן מוצר, מחיר, תמונה, זמינות, מלאי, שעות או מספר WhatsApp. [פרטי חיבור Atlas ובדיקות](docs/ATLAS_HE.md).

תמונות חדשות מהמנהל מועלות כעת ל־Cloudinary; במסד נשמר קישור התמונה בלבד באמצעות מודל Mongoose. העלאה אמיתית ופתיחת התמונה מחדש במנהל ובאתר נבדקו בהצלחה. [פרטי Cloudinary](docs/CLOUDINARY.md).

בקשות הזמנה אמיתיות ושליחתן ל־WhatsApp חסומות ב־Preview. קישורי יצירת קשר כלליים בטלפון, מייל ו־WhatsApp פעילים; הם פותחים את אפליקציית המשתמש ודורשים שליחה ידנית. האתר לא נפרס לשירות חיצוני.

נוספו בחירת יום ושעת איסוף לאורך השבוע, בקשת הצעה לאירוע, מפה וניווט. פרטים והוראות מנהל: [הזמנות שבועיות ויצירת קשר](docs/CONTACT_AND_WEEKLY_HE.md).

לפרטי המיחזור, הוראות הניהול, בדיקות ומגבלות ולרשימת ההשלמות לפני פרסום: [דו״ח המסירה](docs/IMPLEMENTATION_HE.md).

בדיקות שבוצעו בהצלחה: build ו־TypeScript; בדיקות שרת מול MongoDB מבודד; דפדפן במחשב וב־360/390/430 פיקסלים; יצירה/עריכה/תמונה/הסתרה/החזרה באתר הציבורי; תהליך בקשה עם מחיר חסר; ובדיקת persistence לאחר הפעלה מחדש מלאה של האתר והמסד.
